# 🌐 Portal Institucional del GAD Parroquial Chontaduro

Este repositorio contiene el desarrollo del **portal web institucional** del Gobierno Autónomo Descentralizado Parroquial de Chontaduro.  
Su propósito es brindar a la comunidad información clara, accesible y transparente sobre la gestión administrativa, proyectos, obras y participación ciudadana.

## 📁 Contenido del repositorio

- **INDEX.html** → Página principal del portal.  
- **NOSOTROS.html** → Información institucional.  
- **MISION.html** → Misión y visión.  
- **NOTICIAS.html** → Comunicados y novedades.  
- **OBRAS-FUTURAS.html** → Proyectos planificados.  
- **PRESUPUESTO.html** → Detalle del presupuesto anual.  
- **BASE LEGAL.html** → Marco normativo.  
- **CONTACTO.html** → Datos de contacto y formulario.  
- **Assets/** → Recursos gráficos y hojas de estilo.

---

## 🧩 Tecnologías utilizadas

- **HTML5** para la estructura del contenido.  
- **CSS3** para el diseño visual.  
- **GitHub Pages** para la publicación en línea.
